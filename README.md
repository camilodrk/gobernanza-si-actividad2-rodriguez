El ejercicio permitió priorizar los correos relacionados con el acceso activo de un exempleado, el uso de una herramienta de IA con datos de clientes y el envío de información personal a un tercero, debido a sus riesgos para la seguridad y la privacidad. Se identificaron tres vacíos de gobernanza en Café Andino: ausencia de una política de seguridad de la información, falta de un comité de seguridad y carencia de un procedimiento formal de gestión y aceptación de riesgos. El análisis evidenció la importancia de establecer responsabilidades claras entre la alta dirección, los dueños de proceso, TI y el CISO. Finalmente, el contraste con la IA generativa demostró que puede apoyar la identificación de riesgos y proponer acciones, pero sus respuestas deben verificarse con fuentes oficiales y el criterio profesional.
